# Pennywise — Personal Expense Tracker

A modern personal expense tracker and budget dashboard built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Features
- **Dashboard Overview**: Track total spend, monthly spending, daily average, and transaction counts.
- **Visual Analytics**: Interactive canvas donut chart for spending by category and budget progress meters.
- **Budget Tracking**: Set monthly budgets and get real-time remaining vs. over-budget alerts.
- **Transactions Management**: Add, edit, delete, search, and filter expenses by category or date.
- **CSV Export**: Export all logged transactions directly to CSV.
- **Account & Floo Auth Portal**: Animated authentication view with cosmic particle rings and credential storage.
- **Theme Toggle**: Dark mode and light mode support with persistent local storage.

## Local Development
Start a local static server:
```bash
python3 -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).
